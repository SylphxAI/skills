# Review Domain

One domain, ranked findings for a named decision. Open [the domain index](references/INDEX.md) and then **one** matching pack. If none matches, complete the assessment from evidence using [the shared review rhythm](references/review-playbook-skeleton.md).

After several domain reviews of the same candidate, open [multi-review synthesis](references/multi-review-synthesis/METHOD.md).
