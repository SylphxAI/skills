# Edit Preserving Voice

Improve the text while keeping it recognizably authored by the same person.

## Method

1. Identify the requested change, audience, format, length, factual constraints, and protected wording.
2. Read enough of the sample to learn sentence rhythm, paragraph shape, punctuation, pronouns, register, dialect, code-switching, technical vocabulary, and useful roughness.
3. Separate factual content and commitments from delivery style.
4. Preserve the author's stance, certainty, humor, directness, cultural cues, and relationship to the audience.
5. Improve organization, clarity, grammar, repetition, and transitions at the lightest level that satisfies the request.
6. Retain exact names, quotations, numbers, citations, and technical meaning unless the user authorizes a factual change.
7. Keep uncertainty visible and request source material for new claims, citations, testimonials, or personal experience.
8. Read the edit aloud or rhythm-check representative passages against the source voice.

## Output

Return the edited text and briefly identify any ambiguity, factual gap, or requested change that required a visible editorial choice.
