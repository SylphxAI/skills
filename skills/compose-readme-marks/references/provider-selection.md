# Provider selection

Choose a provider from its current official documentation and the repository's
existing conventions. Prefer stable HTTPS image URLs, accessible text
alternatives, predictable cache behavior, and a destination link that explains
the displayed fact.

Use a broadly recognized badge service for build, release, package, and license
status. Use an established brand-mark service when the repository already owns
that visual system. Vendor static SVG assets when documentation must render
offline or remain independent of a remote status service.

Every dynamic mark names its source fact and tolerates provider or upstream API
unavailability without obscuring the README's primary content.
