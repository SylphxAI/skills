# Select Next Work

Do not invent a second graph, coverage table, or coordination ledger. Claim through the team's existing tracker when claim authority exists. Highest theatre is not highest value. Prefer the item that unblocks the current destination with the least new surface.

Use `bound-request-scope` when the request is still mixed. Use `drive-to-delivery` once one objective is accepted.
