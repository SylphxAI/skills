# Record Structured Deliberation

Consensus is not a decision. Collect initial positions independently when hierarchy or early anchoring would shrink the option set. Normalize each proposal into claim, assumptions, strongest reasons, and tradeoffs. Run one focused challenge round on the claims that would actually change the action.

Hand selection to the named decision owner. Record stable dissent instead of erasing it. Use the team's existing decision record; do not invent a second ledger.

Use `analyze-critically` for a single-analyst challenge. Use `review-domain` for subject-specific assessment criteria. Use `optimize-decision-model` when the choice is a constrained allocation rather than a reasoned selection.
