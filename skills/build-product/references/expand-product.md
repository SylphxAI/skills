# Expand Product

Remove the current constraint on a working product while preserving its core journey.

## Method

1. Define the validated product loop, target scale dimension, current baseline, desired capacity or reach, and constraints.
2. Locate the binding product, technical, operational, distribution, or market constraint.
3. Compare a small set of strategies by expected movement in the scale dimension, lifecycle cost, ownership fit, reversibility, and new operating burden.
4. Choose one coherent expansion with an observable result.
5. Implement it at the owning layer using existing product and platform contracts.
6. Add the capacity, telemetry, support, recovery, and operational ownership required by the new scale dimension.
7. Run the expanded path and the original core journey.
8. Measure the target dimension when the request includes a delivered scale claim.

## Output

Return the validated core, scale target, binding constraint, selected expansion, implementation, changed paths run, measured result when available, and new operating responsibilities.
