# Build Product

Use the product's current identity, storage, job, and event providers. Do not invent a second live writer or hide required durability in process memory. Prove the real user path, not only configuration.

Open [event contracts](references/event-contracts.md) when the slice creates, publishes, consumes, delivers, or observes something called an event.
