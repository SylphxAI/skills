# Competing Hypotheses

Chamberlin's multiple working hypotheses and Platt's strong inference are the
method: generate a small set of materially different explanations, ask what
each predicts, and run the observation that can exclude one or more of them.
Heuer's Analysis of Competing Hypotheses is an ancestor; mechanical ACH
matrices have mixed evidence and do not replace the decision owner's judgement.

Do this before reading more:

1. Name the decision the critique would change.
2. Separate observations, inferences, assumptions, and unknowns.
3. Write the leading view and at least one live alternative that is not a
   straw man.
4. Write rejection conditions for each while the result is still unknown.
5. Check base rates, incentives, selection, missing causes, and reversibility.
6. Stop when the next source cannot change the ranking or the action.

Classroom critical thinking — fallacy names, argument maps, "be more
skeptical" — is a hygiene layer. It does not identify causal effects, score
forecasts, or replace domain structure.
