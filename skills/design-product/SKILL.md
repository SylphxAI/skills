# Design Product

Open only the shape pack the product actually is:

- App whose promise is a recurring job: [app product](references/app-product/METHOD.md)
- Play, mastery, or progression: [game product](references/game-product/METHOD.md)
- Multi-tenant public-to-authenticated service: [SaaS web platform](references/saas-web-platform/METHOD.md)

Open [space exploration](references/space-exploration/METHOD.md) only when materially different concepts are still live. Open [marketing automation](references/marketing-automation/METHOD.md) only when authorized journeys and spend are part of this product.
