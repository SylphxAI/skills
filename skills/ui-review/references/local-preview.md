# Local web preview

Load a local web or canvas preview through a browser and inspect the rendered
result, including console or page errors.

Discover the actual preview URL from the product's running server. Open it
with the host browser or the product repository's existing browser test
interface — not an agent-only loopback the human cannot see.

Inspect layout, content, canvas state, clipping, loading, and obvious visual
defects. Exercise the interaction this task changed. For games, visible input
and movement behavior matter in addition to a screenshot.

Match local preview, public preview, released, and live claims to the observed
layer. Open [preview honesty](preview-honesty.md) when reporting what a human
can actually see.

A public temporary URL is `prototype-product`, not this review.
