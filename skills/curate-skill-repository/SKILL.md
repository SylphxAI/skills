# Curate Skill Repository

The unit is a recurring user job with an independently useful artifact, not a folder or generated catalog row. Historical presence is not authority to republish. A deleted scoreable job with a unique remaining mechanism is a rewrite candidate, not a museum piece. A body cannot repair a description the host never selects. Do not invent a host router, catalog control plane, or adoption claim.

Open [repository curation patterns](references/repository-curation-patterns.md) for dispositions and loss review. Open [behavior examples](references/behavior-examples.md) for route boundaries.
