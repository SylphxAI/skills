# Curate Skill Repository

Make a skills repository more useful by improving the skills themselves. The
primary unit is a recurring user job with an independently useful artifact, not
a folder, topic, governance mechanism, or generated catalog row.

## Method

1. Establish the repository boundary, intended users, public or private
   visibility, supported Agent Skills format, canonical branch, host discovery
   contract, and publication policy. Treat validation and listing surfaces as
   support, not the product.
2. Reconstruct the complete relevant corpus from installable entries, active
   proposals, retirement records, default-branch history, and closed-unmerged
   work. Classify sensitivity, audience, license, and publication authority
   before reuse; historical presence is not authority to republish.
3. Judge four facts separately for every capability: recurring-job value,
   current-package value, need for a separate discoverable route, and current
   evidence state. A weak old package does not make its job worthless, and an
   authored package is not observed routing proof.
4. Inspect the portable `name` and `description` under realistic catalog
   pressure, then the body, references, helpers, original source, accepted
   artifact, unique mechanisms, failure modes, authority, and neighbours. The
   body cannot repair a false-negative route if the host never selects it.
5. Compare neighbours by requestable job, independently accepted artifact, and
   acceptance authority. Keep different artifacts separate. Absorb only when
   one canonical owner accepts the whole job and every unique rule, state,
   failure mode, example, helper, and oracle has a destination.
6. Run a false-negative loss review before consolidation. Review the rejected
   or hidden material against the proposed destination without treating the
   preferred disposition as fact. Resolve material disagreement through more
   source inspection or forward tests; preserve unresolved value as a rewrite
   or investigation rather than forcing retirement.
7. Choose `keep`, `rewrite`, `absorb`, `transfer`, `investigate`, or
   `archive-implementation`. Give every decision a semantic reason, canonical
   owner, exact content action, evidence state, and confidence.
8. Improve concise front-loaded descriptions, packages, and behavior examples.
   Exercise positive, nearby-negative, abstention, compound, multilingual,
   ambiguous, correction, and misleading-keyword cases on the supported native
   host when available, then run repository-native format, link, and script
   checks. Record unavailable host behavior honestly.

Read [repository curation patterns](references/repository-curation-patterns.md)
for the four-verdict model, collision dispositions, absorption map, and
false-negative review.

Read [behavior examples](references/behavior-examples.md) when checking route
boundaries and the curation-report artifact.

## Output

Return one curation report with:

- repository boundary, users, visibility, sensitivity, and publication
  authority;
- portfolio verdict and per-capability job, package, route, and evidence facts;
- canonical owner, disposition, exact content action, and confidence;
- absorption map for actual merges and loss review for rejected material;
- missing or weak capabilities, disagreements, and resolving evidence;
- validation run and precise content, candidate, landed, published, and
  installed states.

## Boundaries

- Native hosts own discovery and installation. Do not invent a repository
  router, catalog control plane, qualification gate, or adoption claim.
- Semantic value and disposition remain curation judgments; counts, hashes,
  demand labels, and structural checks are inputs.
- Company standards remain with their company owner. A public skill carries
  only authorized reusable method, not owner-only procedure, secrets, customer
  data, private topology, volatile live facts, or a second body of company law.

This boundary follows the Sylphx company
[agent-method ownership](https://github.com/SylphxAI/owner/blob/main/standards/agents.md)
standard; the source remains company law and this package remains the portable
curation method.
