| HN Algolia | none | L1 | tech discussion |

| Internet Archive | none | L1 | historical pages |
| Open-Meteo / ipify / FX class | none | L1 | structured facts |
| DuckDuckGo HTML class | none | L1 brittle | general search last among free |
| Paid SERP | key | L4 | last resort only |
