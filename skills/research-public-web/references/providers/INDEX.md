# Public research providers

| Provider | Auth | Free class | Role |
|---|---|---|---|
| Host agent web/search tools | host | L0/L1 | prefer when present |
| DuckDuckGo HTML class adapters | none | L1 brittle | general search |
| Wikipedia / MediaWiki API | none | L1 | encyclopedia + revisions |
| HN Algolia | none | L1 | tech discussion search |
| npm / crates.io / PyPI / jsDelivr | none | L1 | package truth |
| Internet Archive | none | L1 | historical pages |
| Open-Meteo / other open data APIs | none | L1 | structured facts when relevant |
| Paid SERP (SerpAPI etc.) | key | L4 | last resort |

Local agent web instruments may appear as host tools—use them when installed, but this skill does not depend on any single vendor MCP.
