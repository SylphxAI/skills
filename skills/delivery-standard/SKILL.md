# Delivery Standard

Apply these policy constraints while another matching skill owns the requested
job. This package is not a standalone product workflow.

Read [references/full-standard.md](references/full-standard.md) when the task
claims or targets a landed, released, deployed, or live state.

## Method

1. Read [references/full-standard.md](references/full-standard.md) for the
   relevant predicates.
2. Apply the strongest matching subset at the owning source, CI, release,
   deployment, or runtime layer.
3. Keep local, candidate, landed, released, deployed, and live observations
   separate in the primary result.
4. Put material evidence and residual authority in the primary artifact or
   status; do not create a second compliance report merely because this policy
   was selected.

## Boundaries

- This standard grants no tools, credentials, deployment authority, or
  permissions.
- The active product repository owns its delivery declaration and product
  contracts.
- Native hosts own installation, update, cache, and live-load readback for
  this package. A host projection is not a second authoring source.
