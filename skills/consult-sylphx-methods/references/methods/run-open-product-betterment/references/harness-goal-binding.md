# Host continuity binding (portable)

## Principle

Skills describe **method**. Hosts own **tool identifiers and goal lifecycle**.

| Do | Do not |
| --- | --- |
| Follow the active host’s continuity/objective APIs under their real names | Paste Codex-, Spiron-, or other host-specific tool ids into Skill text as if universal |
| Set a fixed cycle contract only when the host allows an empty-objective bind | Rewrite/replace objectives on hosts that only allow complete / pause / block |
| Complete only at empty high-EV frontier with evidence | Complete after one cycle or one user message |
| Work without a goal store when the host has none | Invent a fake goal API |

## Cycle contract

Use the cycle contract block in `SKILL.md` as objective **text** when a host permits setting it.

## Replace-forbidden hosts

If replace is forbidden: keep the existing objective; apply the cycle method as working procedure; use only allowed terminal transitions per host policy.
