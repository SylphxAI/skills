# Review Game Economy

Every source has a sink. Baseline play remains viable without paid acceleration. Purchased value is not silently reduced. For randomized rewards, model the actual pity/featured/duplicate machine, not only displayed base rates. A displayed drop rate that the machine does not implement is a false claim.
