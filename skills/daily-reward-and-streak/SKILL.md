# Review Daily Reward And Streak

A disabled loop has zero timers, notifications, background work, or grants. Core utility must not depend on streak or tenure. Server clock is authoritative. Churn-and-rejoin must not be the optimal earning strategy. Client-claimed streaks are not grants.
