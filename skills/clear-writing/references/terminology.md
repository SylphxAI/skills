# Standard terminology

Trigger: naming a concept, translating old internal shorthand, or reviewing skills and agent instructions.

This is the single glossary. Historical labels in the first column are lookup data,
not vocabulary for active guidance. Use the industry term in the second column.
Sources support the replacement concept, not the historical label or every local
policy attached to it. Plain-English descriptions are marked as such; they are
not invented standards. Preserve exact public symbols and legitimate domain uses
described in the context column. Product names stay in the workspace ownership record.

## Maintenance

Add a source and usage context whenever a mapping changes. Do not redefine a
standard term to mean an unrelated internal concept. Run the repository checks
before submitting a terminology change; historical labels may occur only here,
while domain-specific exceptions remain valid in their stated contexts.
