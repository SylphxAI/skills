# Public-share boundary

Classify the artifact before upload. Public hosts receive material already
approved for public disclosure. Private team material uses an authenticated or
short-lived signed route owned by the product or repository.

Review the artifact and its metadata for credentials, session material,
customer data, private source, internal addresses, and embedded attachments.
Use the repository or provider's native secret scanning where available, then
inspect the rendered or extracted content that recipients will receive.

If a credential reaches a public route, rotate it, remove the public object,
and follow the owning incident path. Rotation restores the security boundary;
object removal limits continued exposure.
