# Sylphx Skills

Agent **workflow** skills for Codex, Claude Code, and Grok Build.

## What a skill is

A skill is a **job procedure** users request (design product, build product, review domain, …).  
Depth and engine-specific tooling live in `references/`. Org **policies** live in `docs/policies/` and are not listing skills.
