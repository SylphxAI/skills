# Sylphx Skills

Agent Skills for Codex, Claude Code, and Grok Build.

A skill is a **requestable job** with a specialized procedure. Standards, domain packs, and long matrices live in `references/` under the skill that uses them.

There is **no hard skill-count cap**. Catalogs grow with real jobs; organize by semantics. Author against [skills/author-skill](skills/author-skill/SKILL.md). Model: [docs/MODEL.md](docs/MODEL.md).
