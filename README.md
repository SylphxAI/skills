# Sylphx Skills

[![CI](https://github.com/SylphxAI/skills/actions/workflows/check.yml/badge.svg)](https://github.com/SylphxAI/skills/actions/workflows/check.yml)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](./LICENSE)

**Agent Skills for specialized jobs** — installed via progressive disclosure on
Codex, Claude Code, and Grok Build.

## Model

One skill = one job. Short `description` for discovery; depth in `references/`.
No meta method-bag and no "company vs non-company" gate.

See [`docs/MODEL.md`](./docs/MODEL.md).
